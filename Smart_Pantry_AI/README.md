# Pantry Pulse

Flutter prototype for a Pantry Pulse application.

## Open in Android Studio
1. Extract this ZIP.
2. Open Android Studio.
3. Choose **Open**.
4. Select the extracted `Smart_Pantry_AI` folder.
5. Wait for Flutter/Gradle indexing to finish.
6. Run the app on an emulator or connected Android device.

## Note
This version is a UI prototype. Camera/OCR/barcode and AI services can be integrated next.
